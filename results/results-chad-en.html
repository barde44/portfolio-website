Data Cleaning — Chad Health Indicators

Tools: Python (pandas, numpy, requests, matplotlib, seaborn) Source: World Bank API

Business Problem

Chad faces major health challenges: high infant mortality, unstable vaccination coverage, and a shortage of medical personnel. International organizations and NGOs rely on World Bank data to guide their programs, but this data has significant quality issues: 24.2% missing values, inconsistent formats, and untreated outliers.

"Can we obtain a reliable dataset of 10 health indicators for Chad (2000–2023) to track public health policy progress? Which indicators have the most gaps? How can we impute missing data without biasing trends?"

The goal is to clean and prepare this dataset so it can be used by analysts and decision-makers in the humanitarian sector.

Project Objectives

  • Extract 10 health indicators via the World Bank REST API
  • Assess data quality (completeness, consistency, types)
  • Handle missing values using linear interpolation adapted for time series
  • Detect outliers using the IQR method
  • Validate cross-indicator consistency (e.g., mortality vs. life expectancy)
  • Export a cleaned dataset as CSV with a quality report

Methodology

1. Data Collection

Extraction via the World Bank REST API (api.worldbank.org/v2) for country TCD (Chad), over 2000–2023, for 10 selected indicators.

2. Exploration & Diagnosis

  • Analysis of structure, types, and completeness
  • Identification of missing data patterns by indicator and year
  • Diagnosis: 58 missing values (24.2%), 0 duplicates, heterogeneous formats

3. Cleaning & Imputation

  • Linear interpolation for continuous time series (vaccination, mortality, life expectancy)
  • Median for point data without a clear trend
  • Data type standardization
  • 37 values imputed in total

4. Outlier Detection

  • IQR method (1.5 × interquartile range) applied to each indicator
  • Health expenditure and measles vaccination show the greatest variability

5. Validation & Export

  • Cross-consistency check: mortality cannot increase AND life expectancy increase simultaneously
  • Export of cleaned dataset as CSV + quality report

Visualizations

Key Insights (actual data 2000–2023)

Mortality

  • Infant mortality: dropped from 182 to 100 per 1,000 births (-45% over 24 years)
  • Maternal mortality: sharp decline after 2018 (1,200 → 760 per 100,000 births)

Vaccination

  • Measles vaccination: highly volatile (15% to 65%), reflecting campaign instability
  • Fluctuations make planning difficult for health organizations

Progress

  • Life expectancy: increased from 48 to 55 years (+7 years)
  • Overall improvement despite occasional setbacks

Data Gaps

  • Hospital beds: 87.5% missing data — the most incomplete indicator
  • Physicians per 1,000 pop.: very incomplete data, reflecting the lack of statistical monitoring

Recommendations

  1. Data Quality: infrastructure indicators (beds, physicians) require a better national data collection system
  2. Vaccination: vaccination coverage volatility calls for more stable, long-term programs
  3. Monitoring: use this cleaned dataset as a foundation for an SDG health monitoring dashboard
  4. Automation: schedule periodic extraction and cleaning via the API
