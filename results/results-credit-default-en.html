Credit Default Prediction — Logistic Regression

Tools: Python, scikit-learn, pandas, matplotlib, seaborn, imbalanced-learn Duration: ~6 hours

Business Problem

A financial institution wants to predict credit card payment defaults among its clients. With a default rate of only 3.7%, the dataset is highly imbalanced. Logistic regression with class weighting identifies at-risk profiles while handling this imbalance.

Can we reliably predict a payment default based on payment history and client characteristics?

Project Objectives

  • Analyze variable distributions and class imbalance (3.7% default rate)
  • Apply logistic regression with class_weight="balanced" to handle imbalance
  • Evaluate performance via AUC-ROC, F1-score, precision and recall
  • Optimize the decision threshold to maximize the F1-score
  • Interpret logistic coefficients and odds ratios
  • Validate robustness through stratified 5-fold cross-validation

Model Performance

  • The AUC-ROC of 0.7194 indicates moderate discriminative ability
  • The recall of 0.5848 (threshold 0.5) detects ~59% of defaults
  • Threshold optimization to 0.83 improves F1 from 0.1580 to 0.2879
  • Cross-validation confirms model stability (AUC std = 0.0129)

Identified Limitations

  • The very low default rate (3.7%) makes classification challenging
  • Precision remains low (many false positives) even after threshold optimization
  • A more complex model (Random Forest, XGBoost) could improve performance

Recommendations

  1. Use PAY_0 as the primary indicator of payment default risk
  2. Adjust the decision threshold based on the business cost of false positives vs false negatives
  3. Combine with ensemble models (Random Forest, Gradient Boosting) to improve precision
  4. Implement real-time scoring based on recent payment history
  5. Explore oversampling (SMOTE) to better handle class imbalance
