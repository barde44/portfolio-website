House Price Prediction -- Linear Regression

Tools: Python, scikit-learn, pandas, matplotlib, seaborn, statsmodels, scipy Duration: ~6 hours

Business Problem

A real estate investor wants to estimate the median house price across different neighborhoods in the Boston area. With 13 socio-economic and structural variables, it is essential to build a regression model capable of predicting prices and identifying the most influential factors.

Which variables determine house prices? Can we build a reliable model to estimate property value?

Project Objectives

  • Analyze the distributions and correlations of 13 explanatory variables
  • Build a simple linear regression (RM only) as a baseline
  • Build a multiple linear regression with all 13 features
  • Compare Ridge and Lasso regularization performance
  • Analyze residuals (normality, homoscedasticity, Q-Q plot)
  • Evaluate models through 10-fold cross-validation
  • Identify the most important features via permutation importance

Methodology

1. Exploratory Data Analysis (EDA)

  • 506 observations, 14 columns
  • Median price (MEDV): mean = $21.7k, median = $21.7k, min = $5.0k, max = $42.9k

2. Correlation Matrix

  • Strong correlations with MEDV: RM (+), LSTAT (-), PTRATIO (-)
  • Multicollinearity detected between some variables (RAD/TAX, DIS/AGE)

3. Simple Linear Regression (Baseline)

  • Single variable: RM (average number of rooms)
  • R2 = 0.050, RMSE = 7.82

4. Multiple Linear Regression

  • 13 features used
  • R2 = 0.843, RMSE = 3.18, MAE = 2.55, MAPE = 14.07%

Key Variables

  • LSTAT (% lower status population): most important predictor by permutation
  • DIS (distance to employment centers): strong influence on price
  • RAD (highway accessibility): significant impact
  • 10 out of 13 variables significant in the OLS model (p<0.05)

Regularization

  • Ridge and Lasso produce performances very close to the standard linear model
  • The small gap suggests no major overfitting
  • Regularization confirms the robustness of the linear model

Recommendations

  1. Use multiple regression (13 features) as the reference model (R2 = 0.843)
  2. Monitor LSTAT and DIS as priority indicators for real estate estimation
  3. Test non-linear models (Random Forest, Gradient Boosting) to capture complex relationships
  4. Explore feature engineering (interactions, polynomial transformations) to improve MAPE
  5. Collect additional data (living area, property condition, renovation year) to enrich the model
