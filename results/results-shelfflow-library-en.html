ShelfFlow — Personal Library Management System

Tools: Python 3.x, Streamlit, pandas, pytest, JSON Duration: ~8 hours

Business Problem

A developer or data engineer needs a reliable system to manage a technical book collection. The system must support full CRUD operations, persist data in JSON, validate inputs and provide a modern, bilingual user interface.

Project Objectives

  • Design a modular Python architecture (classes, modules, separation of concerns)
  • Implement full CRUD with JSON persistence and atomic writes
  • Build an interactive web interface with Streamlit (bilingual EN/FR)
  • Write unit and robustness test suites with pytest
  • Handle edge cases: duplicates, empty fields, corrupted JSON, missing files

Architecture and Best Practices

Atomic Writes

Saving uses tempfile.NamedTemporaryFile + os.fsync + os.replace to guarantee no data is lost if a crash occurs during writing.

Robust Validation

  • Empty fields rejected with clear error messages
  • Duplicates detected via case-insensitive comparison
  • Corrupted JSON or invalid structure detected on load
  • Failed updates preserve original state (rollback)

Testing

14 tests covering basic CRUD operations (8 tests) and edge case robustness (6 tests): empty fields, duplicates, corrupted JSON, invalid structure, conflicting updates, missing files.
