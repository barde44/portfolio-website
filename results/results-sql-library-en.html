LibraryDB -- Relational Library Management System

Tools: SQLite, SQL, Python, Streamlit, pandas Duration: ~6 hours

Business Problem

A university library needs a system to manage its book catalog, track loans from registered readers and identify overdue books. The system must enable analytics on reading habits, most represented authors and monthly activity.

Project Objectives

  • Design a normalized relational schema (5 tables, foreign keys, constraints)
  • Write advanced analytical SQL queries (joins, aggregations, subqueries, date functions)
  • Create SQL views to simplify recurring analyses
  • Optimize performance with targeted indexes
  • Build an interactive Streamlit interface to explore the database in real time
