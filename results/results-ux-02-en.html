FitBook — Mobile Booking App

Main tool: Figma Program: Future Interns — UI/UX Design Internship

Business Problem

Users of a fitness session booking service (FitBook) need a simple and fast mobile appointment process. The current booking flow is too long, with no instant confirmation or reminders.

"How to enable booking in 3 steps maximum, with instant confirmation and automatic reminders?"

Project Objectives

  • Create personas and user context
  • Map the complete user flow for booking
  • Create wireframes then high-fidelity mockups (7+ screens)
  • Design a 3-step booking flow
  • Apply a clean design with micro-interactions

Key UX Insights

3-Step Flow

  • A 3-step booking flow (trainer → date → confirmation) reduces drop-off rate
  • Each step has a single, clear objective

Interactive Calendar

  • Time slots visible directly under the calendar, no extra page needed
  • Color coding (available / selected) for instant reading

Mobile-First Design

  • Action buttons in the thumb zone, bottom navigation bar
  • Green palette evoking wellness and health
