FitBook — Application de réservation mobile

Outil principal : Figma Programme : Future Interns — Stage UI/UX Design

Problématique métier

Les utilisateurs d'un service de réservation de séances de fitness (FitBook) ont besoin d'un processus de prise de rendez-vous simple et rapide sur mobile. Le parcours actuel est trop long, sans confirmation instantanée ni rappels.

« Comment permettre une réservation en 3 étapes maximum, avec confirmation instantanée et rappels automatiques ? »

Objectifs du projet

  • Élaborer des personas et un contexte utilisateur
  • Cartographier le user flow complet de réservation
  • Créer des wireframes puis des maquettes haute fidélité (7+ écrans)
  • Concevoir un flux de réservation en 3 étapes
  • Appliquer un design épuré avec micro-interactions

Méthodologie

1. Recherche UX

Création d'un persona et d'un user context pour comprendre les motivations et frustrations des utilisateurs de l'application de fitness.

2. User Flow

Cartographie du flux complet : Onboarding → Accueil → Sélection de service → Choix du coach → Sélection date/heure → Confirmation → Succès.

3. Wireframing & Design haute fidélité

Wireframes validant la structure, puis maquettes HD avec palette verte (fitness/bien-être), illustrations et micro-interactions.

Principaux insights UX

Flux en 3 étapes

  • Un flux de réservation en 3 étapes (coach → date → confirmation) réduit le taux d'abandon
  • Chaque étape a un objectif unique et clair

Calendrier interactif

  • Créneaux horaires visibles directement sous le calendrier, pas de page supplémentaire
  • Code couleur (disponible / sélectionné) pour une lecture instantanée

Design mobile-first

  • Boutons d'action dans la zone de pouce, navigation bottom bar
  • Palette verte évoquant le bien-être et la santé

Recommandations

  1. Notifications push : rappels automatiques avant chaque séance
  2. Tests utilisateurs : valider le flux avec de vrais utilisateurs
  3. Paiement : intégrer un processus simplifié (carte enregistrée, mobile payment)
  4. Accessibilité : vérifier les contrastes sur différentes tailles d'écran
