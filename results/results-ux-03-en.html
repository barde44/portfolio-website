CRM Dashboard — UI Design

Main tool: Figma Program: Future Interns — UI/UX Design Internship

Business Problem

A digital agency needs an intuitive CRM interface to manage client relationships: contacts, opportunities, sales pipeline and performance metrics. The existing tool overwhelms users by displaying too much information simultaneously.

"How to present key data (contacts, opportunities, pipeline) without overwhelming the user?"

Project Objectives

  • Design a complete design system with reusable components
  • Create high-fidelity mockups for 6 views on Figma
  • Structure navigation with sidebar and tabs
  • Design metric cards for KPIs
  • Integrate an interactive table and a kanban pipeline

Key UX Insights

Information Hierarchy

  • KPI cards at the top (Total Leads, Active Clients, Revenue, Tasks Due) for instant overview
  • Kanban pipeline in 5 columns (New → Contacted → Proposal Sent → Negotiation → Closed Won)

Sidebar Navigation

  • 6 views accessible in one click: Dashboard, Leads, Clients, Tasks, Analytics, Settings
  • Active view visually distinct for user orientation

Design to Code

  • Design was implemented in React + Tailwind CSS (shadcn/ui), proving technical feasibility
  • Figma components map directly to React components
