Dashboard CRM — Design UI

Outil principal : Figma Programme : Future Interns — Stage UI/UX Design

Problématique métier

Une agence digitale a besoin d'une interface CRM intuitive pour gérer ses relations clients : contacts, opportunités, pipeline de ventes et métriques de performance. L'outil existant surcharge l'utilisateur avec trop d'informations affichées simultanément.

« Comment présenter les données clés (contacts, opportunités, pipeline) sans surcharger l'utilisateur ? »

Objectifs du projet

  • Concevoir un design system complet avec composants réutilisables
  • Créer des maquettes haute fidélité pour 6 vues sur Figma
  • Structurer la navigation avec sidebar et onglets
  • Concevoir des cards métriques pour les KPI
  • Intégrer une table interactive et un pipeline kanban

Méthodologie

1. Recherche UX

Persona : Sarah Johnson, 32 ans, Sales & Account Manager dans une agence digitale. Gère les prospects, suit les deals et assure l'onboarding client. Frustrations : leads éparpillés dans les emails, pas de visibilité pipeline, oubli de follow-ups.

2. User Flow

Flux principal : Dashboard (vue globale) → Leads (pipeline kanban) → Clients (table interactive) → Tasks (suivi) → Analytics (rapports) → Settings.

3. Wireframing

6 wireframes couvrant toutes les vues du CRM : Dashboard, Leads, Clients, Tasks, Analytics, Settings.

4. Intégration front-end

Le design a été implémenté en React + Tailwind CSS avec des composants shadcn/ui, démontrant la faisabilité technique du design system.

Hiérarchie de l'information

  • KPI cards en haut (Total Leads, Active Clients, Revenue, Tasks Due) pour une vue instantanée
  • Pipeline kanban en 5 colonnes (New → Contacted → Proposal Sent → Negotiation → Closed Won)

Navigation sidebar

  • 6 vues accessibles en un clic : Dashboard, Leads, Clients, Tasks, Analytics, Settings
  • Vue active visuellement distincte pour l'orientation de l'utilisateur

Du design au code

  • Le design a été implémenté en React + Tailwind CSS (shadcn/ui), prouvant la faisabilité technique
  • Les composants Figma correspondent directement aux composants React

Recommandations

  1. Tests utilisateurs : valider la navigation et la hiérarchie des métriques auprès de vrais commerciaux
  2. Responsive tablette : adapter les maquettes pour l'usage terrain
  3. Accessibilité : auditer les contrastes et la navigation clavier
  4. Intégration back-end : connecter les composants à une API CRM réelle
