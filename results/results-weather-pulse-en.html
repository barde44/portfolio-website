WeatherPulse -- Weather API Data Collection & SQL Storage

Tools: Python, requests, SQLite, Streamlit, pandas Duration: ~8 hours

Business Problem

A tourism company wants to automate weather data collection for its destinations to provide personalized travel recommendations based on current and historical weather conditions.

Project Objectives

  • Connect to the OpenWeatherMap REST API and retrieve real-time JSON data
  • Clean and normalize JSON responses (timestamps, units, null values)
  • Design a SQLite schema with tables, indexes and analytical views
  • Implement 8 advanced analytical SQL queries
  • Build an interactive bilingual Streamlit dashboard (FR/EN)
