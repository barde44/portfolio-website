WeatherPulse -- Collecte de Donnees Meteo via API et Stockage SQL

Outils : Python, requests, SQLite, Streamlit, pandas Duree : ~8 heures

Problematique metier

Une entreprise de tourisme veut automatiser la collecte de donnees meteo pour ses destinations afin de fournir des recommandations personnalisees basees sur les conditions actuelles et historiques.

Objectifs du projet

  • Connecter l'API REST OpenWeatherMap et recuperer les donnees JSON en temps reel
  • Nettoyer et normaliser les reponses JSON (timestamps, unites, valeurs nulles)
  • Concevoir un schema SQLite avec tables, index et vues analytiques
  • Implementer 8 requetes SQL analytiques avancees
  • Construire un dashboard Streamlit interactif bilingue (FR/EN)
